# Changelog

## 0.1.0

- Syntax highlighting for `.cssql` files: SQL, Razor transitions/directives/comments, and embedded C#.
- File icons for `.cssql` and `.orm` files (light and dark variants).
- `.orm` files: JSON language features plus Visual Studio-style nesting of generated `.orm.cs`/`.orm.js`/`.orm.mjs`/`.orm.d.ts` files.
